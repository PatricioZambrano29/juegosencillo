# 💀 El Ahorcado

Juego del Ahorcado desarrollado con HTML, CSS y JavaScript puro.  
Proyecto académico — Interfaces Humano Computador.

## 🎮 Características

| Característica | Descripción |
|---|---|
| 🧑 Registro de usuario | Nombre + avatar personalizado |
| 🎯 Niveles | Fácil, Medio, Difícil |
| 🆚 Modos de juego | Un jugador (vs. máquina) y Versus (el usuario pone la palabra) |
| 🏆 Historial | Top 50 jugadores con mejor puntuación, filtrable por nivel |
| 🃏 Comodines | Revelar letra, Eliminar letras falsas, Mostrar pista |
| 📥 Descarga | Resultado individual y tabla de historial en `.txt` |
| 📂 Categorías | General, Animales, Países, Frutas, Tecnología |
| ⌨️ Teclado físico | Se puede jugar con el teclado del PC |

## 🚀 Cómo ejecutar

Solo abre `index.html` en cualquier navegador moderno.  
No requiere servidor ni dependencias.

## 📁 Estructura

```
├── index.html   # Estructura y pantallas del juego
├── style.css    # Estilos y tema oscuro
├── words.js     # Base de palabras por categoría y nivel
├── game.js      # Lógica del juego
└── README.md
```

- HTML5 semántico

- JavaScript ES6+ sin frameworks
- LocalStorage para persistencia del historial
- Google Fonts (Creepster + Nunito)
